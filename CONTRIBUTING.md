# Contributing

Thank you for wanting to improve this skill.

This repository is maintained by one person: only the maintainer changes it. You are welcome to propose changes:

- **Ideas, problems, lessons from your own videos**: open an issue and describe what happened, what you expected and,
  if you can, a frame or a short clip that shows it.
- **Concrete changes**: fork the repository, make the change on a branch and open a pull request. Explain why the change
  helps and how you tested it (for scripts: the command you ran and what it produced).

The maintainer reviews every proposal and decides whether, and how, it goes into the skill. A proposal can be taken
in part or rewritten to fit the rest of the skill.

Please do not include API keys, personal data, or footage of people without their consent in issues or pull requests.
